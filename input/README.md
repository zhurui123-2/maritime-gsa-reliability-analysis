# Input data

Place the original, unmodified data files here:

- `AIS_2024_01_01.csv` to `AIS_2024_01_07.csv`
- `hrrr_3km_YYYYMMDDHH.grib2` and matching metadata files
- `2024-v223-10062026-EU MRV Publication of information.xlsx`

The raw data are intentionally not duplicated in this submission-code folder.
Run `align_shipping_data.py` from the repository root to create the aligned
dataset used by all experiments.
